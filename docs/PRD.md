# DictBox V3 产品需求文档

> 文档版本：v3.1
> 最后更新：2026-08-25
> 状态：当前发布分支基线

## 1. 产品定位

DictBox 是一款浏览器快速查词扩展。用户可以通过 Chrome 地址栏 `db + 空格`、工具栏弹窗或扩展内部查询页获取中英双向及多语言释义。

核心原则：

- 新用户无需注册或 API Key 即可完成第一次查询。
- Popup 负责快速判断，完整页负责阅读全部释义和例句。
- 普通设置与高级 API 参数分层展示。
- API Key 仅保存在当前设备，查询文本发送到用户选择的服务商。

## 2. 当前功能

### P0 核心查询

- Omnibox 输入 `db + 空格 + 查询内容`，停顿 500ms 后显示精简建议。
- 支持单字符、单词和最长 80 字符的短语。
- 默认使用 MyMemory 免费查询，无需 API Key。
- 自动检测原语言；中文输入且目标语言为中文时自动切换为英语。
- Enter 打开 DictBox 内部完整查询页；空查询页不会自动发送网络请求。
- 内存与持久化缓存、请求去旧、Provider fallback 和安全错误映射。

### P0 设置与安全

- 支持免费查询、OpenAI、Gemini、Claude、DeepSeek 和 OpenAI 兼容自定义服务。
- 官方服务仅要求用户填写 API Key；模型提供建议值，Endpoint 收入高级设置。
- “测试并保存”在连接成功后持久化当前配置。
- 自定义服务仅申请用户填写 Origin 的主机权限。
- 恢复全部默认设置前明确提示会删除所有 API Key，并要求二次确认。
- 普通设置使用 `storage.sync`，API Key 使用 `storage.local`。

### P1 界面与历史

- Popup 最多显示 2 个词性组、5 条释义，其余进入完整页。
- Popup 高度随空状态、结果长度自然增长，上限 620px。
- 最近查询最多 5 条，支持重新查询、单条删除、全部清空和撤销。
- 完整页首屏包含查询框、词头、服务商、语言方向、主要释义和复制操作。
- Popup、完整页和 Omnibox 使用一致的查询服务与语言元信息。

### 支持语言

目标语言共 13 种：简体中文、英语、日语、韩语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语、阿拉伯语、泰语、繁体中文；原语言另支持自动检测。

## 3. 非功能要求

- Manifest V3，Chromium 与 Firefox 双目标构建。
- 外部文本仅通过 DOM `textContent` 渲染，不注入 HTML。
- API Key 不进入 URL、日志、页面 HTML 或公开错误消息。
- 缓存命中目标低于 50ms；网络查询提供超时、取消和错误分类。
- 自动化覆盖核心模块、后台消息、Omnibox、语言反转、设置结构和页面入口。

## 4. 发布验收

- 全新配置下 30 秒内完成免费查询。
- `hello` 默认显示到简体中文；`你好` 默认显示到英语。
- 已保存的 DeepSeek 等模型服务可测试、保存并在 Popup 中查询。
- 直接打开 `result.html` 或点击 Logo 不发送查询。
- 自定义服务拒绝权限后有可恢复提示，授权后测试与真实查询均可用。
- 危险重置在确认前不得修改任何存储。
- Chromium 自动化、构建和 Chrome Computer Use 全流程验收通过。

## 5. 后续规划

在当前闭环稳定后再评估生词本、TTS、网页划词、账号同步和深色模式；这些能力不应先于核心查询可靠性和页面职责一致性。

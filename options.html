查询服务

免费查询无需配置；也可以使用自己的模型 API 获得更完整的词典结果。

已选择免费查询

无需注册或填写密钥，保存后即可开始中英双向查询。免费服务返回精简翻译结果。

高级设置

只有自定义部署或代理服务需要修改。

查询语言

建议保持自动检测；输入中文且目标为中文时会自动翻译成英语。

隐私说明

普通设置可通过浏览器同步；API Key 仅保存在当前设备。查询文本会发送到你选择的服务商。

重置与清除

恢复全部默认设置会同时删除所有已保存的 API Key。

删除所有设置和 API Key？

此操作无法撤销。所有服务商密钥、模型设置和语言偏好都会恢复为默认值。
